# Data Structure Lab

A collection of C++ programs for learning and practicing fundamental data
structures and algorithms.

## Data Structures

- Arrays and matrices
- Singly linked lists
- Stacks and queues
- Binary trees and binary search trees
- Graphs using breadth-first search (BFS) and depth-first search (DFS)

## Algorithms and Topics

- Linear and binary search
- Bubble, selection, insertion, merge, and quick sort
- Infix-to-postfix conversion and postfix expression evaluation
- Matrix addition and multiplication
- Basic string operations and tree traversals

The programs are written in C++ and focus on implementing each concept from
scratch for hands-on data structure and algorithm practice.
